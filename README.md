# TAO Reborn (protótipo)

Jogo tático 1x1 por turnos em grade hexagonal. Protótipo jogável no navegador, sem instalação, funciona offline.

Jogar: abra o link da página (GitHub Pages) ou o arquivo `index.html`.

Modos: contra a IA ou dois jogadores no mesmo aparelho. Feedback: abra uma issue ou fale direto com o autor.

Projeto pessoal em fase de teste. Nomes, unidades e arte originais.
